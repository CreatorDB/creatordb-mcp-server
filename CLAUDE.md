# CLAUDE.md

Guidance for Claude Code and other AI coding agents working in this repository.

## Writing PRs and commit messages

This repository is public. PR titles, PR descriptions and commit messages are visible to anyone, and commit messages are permanent once merged.

- Describe what the change adds or states, in the present tense: "This documents the `isPodcast` field", "Ratio filters take a decimal from 0 to 1".
- Don't narrate what was missing before, what agents or users got wrong, or how long something went undocumented. Avoid lines like "nothing told agents this field exists" or "agents guessed percentages and got empty results".
- Before pushing, check the title, description and commit message for words like "already", "didn't", "wasn't", "missing", "previously", "stale" and "wrong", and reword any that describe a past gap.
